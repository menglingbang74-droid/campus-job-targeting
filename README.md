# campus-job-targeting：校招目标行业与公司定位

帮在校生和应届生把"我这个专业能干什么"变成一份**能照着投的公司清单**。

## 它解决什么问题

学生问"我是 XX 专业该找什么工作"，常见的回答是行业介绍加一堆职业倾向测试，看完还是不知道投哪家。这个技能的输出是三样东西：

1. **赛道判断**：从专业和经历推导出可行的行业方向，并按冲刺、匹配、保底分权。
2. **分层公司清单**：每家公司配具体岗位名、投递理由、需要补什么。
3. **当天能做的动作**：比如"今晚把两篇课程论文改成行业观察稿"。

另外内置了纠偏规则：投了很多家没回音、只投头部没保底、把稳定当第一诉求却投市场化岗位，这几种情况会先被指出来，再谈方案。

## 适用对象

在校生、应届生、考研失败转就业的人，以及投简历受挫需要重新定位的人。理工、文科、专科、研究生都有对应的处理规则。

## 触发词

说出下面任意一类话就行：

- "我是 XX 专业，该找什么工作"
- "帮我推荐目标公司""有哪些公司值得投"
- "选行业方向""校招怎么定位"
- "我这个专业除了本专业还能去哪""跨专业求职怎么选"
- "文科生 / 理科生有哪些出路"
- "投了很多家没回音，是不是方向有问题"

## 目录结构

```
campus-job-targeting/
├── SKILL.md                       主文件：触发词、三阶段流程、输出模板、交互约束
├── references/
│   ├── industry-tracks.md         专业到赛道的映射速查（理工、文科、交叉、专科）
│   ├── company-sourcing.md        公司名单怎么来、怎么核实、哪些不能编

```

采用渐进式加载：`SKILL.md` 常驻，三份 references 按需读取，避免占满上下文。

## 设计上的几条硬约束

| 约束 | 为什么 |
| --- | --- |
| 一次最多问三个问题 | 连环提问会把学生劝退 |
| 不给精确薪资、招聘人数、录用率 | 这些会变，编出来就是误导，统一给区间并标注"参考" |
| 必须给出明确建议（主攻 X，B 计划 Y） | 摆完利弊不说选哪个等于没干活 |
| 每条公司推荐必须配岗位名 | 只有公司名的清单没法直接用 |
| 不替用户联系内推、不美化简历 | 边界问题 |
