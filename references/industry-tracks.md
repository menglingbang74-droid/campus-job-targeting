# 赛道映射参考

用于把"某个专业"推导成"可以投的几类行业"。速查表里的岗位是常见出口，不是全部，落到具体公司前仍需按 `company-sourcing.md` 核实。

## 一、推导方法：三步走

专业名字不等于岗位名字。按这三步推：

1. **拆核心课**：列出这个专业最核心的 3 到 5 门课，它们决定了你能上手干什么。
2. **抽出可迁移技能**：把课程翻译成能力词（会看图纸、会跑仿真、会写长文、会做实验数据、会跟人谈）。
3. **匹配雇主类型**：同一个能力在不同雇主那里叫不同的岗位，见下一节的四类雇主框架。

举例：给排水科学与工程 → 核心课是水力学、水处理工艺、给排水管网 → 可迁移技能是"工艺调试、水质指标、泵阀管路、设备巡检" → 半导体厂务 / 面板厂务 / 光伏锂电废水站 / 市政水务集团 / 环保工程公司都能去。

## 二、四类雇主框架（同一专业的门槛差异主要在这里）

| 类型 | 是谁 | 招人特点 | 适合什么人 |
| --- | --- | --- | --- |
| 甲方工厂 | 有生产线的实体企业（半导体厂、汽车厂、食品厂、药厂） | 招"厂务 / 工艺 / 设备 / 质量"，看重稳定和倒班适应 | 想在一个地方沉淀技术、接受倒班的人 |
| 主机厂与品牌方 | 出成品的公司（整车厂、整机厂、消费品牌） | 研发门槛高，供应链、质量、售后门槛低 | 学校层次好、想要职业起点高的人 |
| 零部件与设备商 | 给主机厂供货的上游（零部件、仪器、耗材、耗材配方） | 数量最多，常年招人，销售与技术支持岗密集 | 学校层次一般、愿意跑客户的人 |
| 工程总包与服务商 | 做项目交付的公司（设计院、总包、监理、运维外包、第三方检测） | 出差多、项目制，起薪不一定低但强度大 | 想快速见多识广、接受驻场的人 |

**判断口诀**：层次高冲主机厂，层次一般走供应商，想攒本事去甲方，想快速见世面去总包。

## 四、院校层次的权重怎么用

| 层次 | 在校招里的实际作用 |
| --- | --- |
| 985 / C9 | 大厂核心岗、央企总部、选调的主要生源地，头部岗位的第一道筛 |
| 211 / 双一流 | 多数内容、运营、管培、职能岗能过初筛；头部技术岗需要额外条件 |
| 行业特色院校 | 在本行业内认可度高于同层次综合院校（电力、交通、化工、师范、纺织类尤其明显） |
| 普通一本 | 区域内的中坚企业、细分龙头、中小厂是主战场 |
| 二本 / 独立学院 | 泛文科赛道竞争极吃亏，建议优先走有硬门槛或愿意培养人的岗位 |
| 专科 | 按第三节的专科路径走，不要投本科门槛岗位假装"冲刺" |

**行业特色院校优先于院校层次**：一所电力类普通一本进电网体系的概率，高于综合类 211 的弱势专业。遇到特色院校先问行业对口通道。

## 五、城市取舍（攒钱视角）

同样是长三角、珠三角，差别主要在生活成本和产业密度。以下为定性判断，具体数字请用当地租房平台核实。

| 城市群 | 产业特点 | 攒钱的代价 |
| --- | --- | --- |
| 上海 | 岗位最多、天花板最高，总包和消费互联网密集 | 房租和通勤吃掉一大部分涨薪 |
| 杭州 | 电商、跨境电商、SaaS 密集，文科岗相对友好 | 生活成本低于上海，竞争强度高于苏锡 |
| 苏州 / 无锡 | 制造业强， semiconductors、装备、新材料密集 | 文科岗偏少，但成本低、制造业 ToB 销售岗多且竞争者少 |
| 南京 | 国企、研究所、出版教育体系密集，节奏偏慢 | 薪资中位偏低，胜在稳定与生活成本 |
| 深圳 / 广州 | 硬件、跨境出海、消费品 | 民企多、节奏快，租房成本接近上海 |
| 成渝 / 中部省会 | 内需与制造业承接，离家近的可能选项 | 薪资低于沿海，胜在离家与生活成本 |

**给"想在 N 年攒够一笔钱"的人的判断**：不要只看起薪，看"起薪减去生活成本"。杭州与苏锡的组合经常优于上海。

## 六、三条容易踩的坑

1. **把专业名字当岗位名字**："环境工程"不等于"环保公司"，它的对口雇主分布在工厂、设计院、检测机构、药剂厂商四类里。
2. **只看行业不看雇主类型**：同样是"新能源"，主机厂、电池厂、设备商、运维外包商的门槛可以差两个档次。
3. **漏掉比本专业更值钱的相邻行业**：一个专业常有薪资曲线更好的相邻去向（中文去做商家运营，机械去做非标自动化设备商）。速查表的第二、三列别跳过。
